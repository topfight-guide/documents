# Topfight PvP Documents

A collection of documents all aimed to spread knowledge of pvp and mechanics for 1.8.9 Minecraf PvP topfight - one of the most advanced pvp systems in all of minecraft.

These documents will be displayed as an organized collection in our discord server

Because there is so much complexity to the nature of 1.8, this can't be done alone. If you want to contribute - whether by spreading your knowledge, correcting typos, and formating the docs to make it more readable - all help is appreciated :)

To contribute, open a pull request and make your edits. If approved, the documents will be updated in the discord shortly.
